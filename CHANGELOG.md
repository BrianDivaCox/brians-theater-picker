# Changelog

## [v1.0.1] - 2026-09-30

- Added 'Only Streaming' filter toggle to exclude rental movies.
- Integrated TMDB subscription and free streaming monetization types.
- Client-side validation guarantees all suggested movies are streaming.
- Auto-syncs toggle state when selecting theater or platform pills.

## [v1.0.0] - 2026-09-30

- Redesigned cinema interface matching Brian's Theater aesthetic.
- Added streaming platform filter pills for quick discovery.
- Added bulk suggestions mode for multiple movie recommendations.
- Implemented multi-page random catalog sampling across TMDB.
- Display high-resolution movie posters and runtime badges.
- One-click copy formatted for theater schedules and Discord.
- Added selectable checkboxes for bulk clipboard export.
- Fully responsive layout for mobile, tablet, and desktop.
